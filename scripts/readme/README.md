# README images

`scripts/render-readme.sh` renders `sign.html` (one sign per section, the text after `#`) and `steps.html` into
`assets/readme/`.

`assets/readme/hero.png` is a still of clod.farm's own scene: serve `site/`, open `index.html` with the card, goal and
FAQ hidden, and screenshot it at 1280x460, device scale 2.
